SixthSense mengubah sensor magnet bawaan smartphone Anda menjadi detektor medan elektromagnetik (EMF) yang presisi.

CARA KERJANYA
Smartphone Anda memiliki magnetometer — sensor yang sama yang digunakan pada kompas digital. SixthSense membaca sensor ini secara real-time dan memvisualisasikan perubahan medan elektromagnetik di sekitar Anda. Sumber umum meliputi peralatan listrik, komputer, kabel listrik, dan router.

FITUR

▸ METERAN JARUM (Gratis)
Meteran EMF analog klasik menampilkan kekuatan medan dalam mikrotesla (µT).

▸ GRAFIK LANGSUNG (Gratis)
Grafik bergulir sumbu X, Y, dan Z melacak medan magnet selama 60 detik terakhir.

▸ KALIBRASI (Gratis)
Tetapkan nilai dasar. SixthSense hanya menyorot penyimpangan di atas nilai dasar tersebut.

▸ MODE RADAR (Pro)
Radar melingkar yang berputar menandai anomali medan sebagai blip secara real-time.

▸ UMPAN BALIK SUARA (Pro)
Tiga paket suara: Klik Geiger, Ping Sonar, Drone Menyeramkan. Laju klik meningkat seiring kekuatan medan.

▸ REKAMAN SESI (Pro)
Simpan pemindaian Anda sebagai file data bertanda waktu.

▸ TANPA IKLAN (Pro)
Hapus iklan banner.
