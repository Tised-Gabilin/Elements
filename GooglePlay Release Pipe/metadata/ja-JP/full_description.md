SixthSense は、スマートフォンに内蔵された磁気センサーを、精密な電磁場（EMF）検知器に変えます。

検知できるもの
スマートフォンには磁力計が内蔵されています——デジタルコンパスと同じセンサーです。SixthSense はこのセンサーをリアルタイムで読み取り、周囲の電磁場の変化を可視化します。主な発生源は、家電製品、パソコン、電源ケーブル、ルーターなどです。

機能

▸ 針式メーター（無料）
クラシックなアナログ EMF メーターが磁場強度をマイクロテスラ（µT）で表示します。空間を移動するにつれて、針が即座に反応します。

▸ ライブグラフ（無料）
X・Y・Z 軸のスクロールグラフが、過去60秒間の磁場変化を追跡します。

▸ キャリブレーション（無料）
任意の場所で基準値を設定。SixthSense はその基準を超えた変動——異常値のみを表示します。

▸ レーダーモード（プロ版）
円形スキャンレーダーが磁場の異常をリアルタイムでブリップとして表示します。

▸ サウンドフィードバック（プロ版）
3つのサウンドパック：ガイガーカウンタークリック、ソナーピング、不気味なドローン音。磁場が強くなるほどクリック音が速くなります。

▸ セッション録音（プロ版）
スキャン内容をタイムスタンプ付きデータファイルとして保存・エクスポートできます。

▸ 広告なし（プロ版）
バナー広告を非表示にして、中断なくスキャンを楽しめます。

使い方
1. アプリを開き、電磁場の影響が少ない場所でキャリブレーションを行う
2. 調べたい空間をゆっくり歩く
3. 針・グラフ・レーダーが磁場の変化にどう反応するか観察する
4. パソコン・電子レンジ・分電盤に近づけると、即座にリアルな数値が変化
