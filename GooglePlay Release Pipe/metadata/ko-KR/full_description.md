SixthSense는 스마트폰에 내장된 자기 센서를 정밀한 전자기장(EMF) 감지기로 변환합니다.

감지 원리
스마트폰에는 자력계가 내장되어 있습니다——디지털 나침반에 사용되는 것과 동일한 센서입니다. SixthSense는 이 센서를 실시간으로 읽어 주변 전자기장의 변화를 시각화합니다. 주요 발생원으로는 가전제품, 컴퓨터, 전원 케이블, 라우터 등이 있습니다.

기능

▸ 바늘 계기판 (무료)
클래식 아날로그 EMF 미터가 자기장 강도를 마이크로테슬라(µT)로 표시합니다.

▸ 실시간 그래프 (무료)
스크롤되는 X, Y, Z축 그래프가 지난 60초간의 자기장 변화를 추적합니다.

▸ 캘리브레이션 (무료)
기준값을 설정하세요. SixthSense는 그 기준을 초과하는 편차——이상값만 강조합니다.

▸ 레이더 모드 (프로)
원형 스캔 레이더가 자기장 이상을 실시간으로 블립으로 표시합니다.

▸ 사운드 피드백 (프로)
3가지 사운드 팩: 가이거 클릭, 소나 핑, 으스스한 드론. 자기장이 강해질수록 클릭 속도가 빨라집니다.

▸ 세션 녹화 (프로)
스캔 결과를 타임스탬프가 찍힌 데이터 파일로 저장하고 내보낼 수 있습니다.

▸ 광고 없음 (프로)
배너 광고를 제거하여 방해 없이 스캔할 수 있습니다.

사용 방법
1. 앱을 열고 전자기장 간섭이 적은 곳에서 캘리브레이션 수행
2. 스캔하려는 공간을 천천히 걸어다님
3. 바늘, 그래프, 레이더가 자기장 변화에 반응하는 것을 관찰
4. 노트북, 전자레인지, 전기 패널 가까이 가져가면 즉각적인 실제 수치 변화 확인
